# Ontology — nodes

Extends HANDOFF 001/002 ontology. Does not replace it.

```text
ROOT      = MEMORY
TRUNK     = LAW
BRANCH    = CONTEXT / LINEAGE
THING     = PORTABLE OBJECT
THREAD    = RELATIONSHIP
AIRLOCK   = EQUALIZATION CHAMBER
SPLIT     = DISJOINT SUBJECT GATE
GATOR     = EXECUTOR TALON
SENTINEL  = WATCHER TALON
```

```text
LORE      explains
LAW       constrains
MATH      formalises
CODE      enforces
NODES     execute          ← Gator, not Sentinel
HASHES    identify
RECEIPTS  prove
HUMANS    choose
```

Do not collapse:

```text
GATOR      ≠ ASSISTANT-THAT-KNOTS

AIRLOCK    ≠ SSO PRODUCT
LOGIN      ≠ OWNERSHIP OF THE PLACE
TRACE      ≠ VERSION HISTORY

WEIGHT     ≠ SCORE
```
