# LITHOS // PUBLIC HANDOFF 002

### THE THING THAT SURVIVES

```text
HANDOFF 001
Where does a Thing belong?

HANDOFF 002
What remains true when that Thing changes?
```

A file usually belongs to the application that created it.

A Photoshop file belongs to Photoshop.

A Blender file belongs to Blender.

A project lives in one folder until somebody exports it, uploads it, copies it, screenshots it, converts it, sends it somewhere else and slowly loses track of which version was actually the thing.

LITHOS begins with a different assumption.

**The Thing should survive the application.**

```text
THING://0041
```

It may begin as a model.

```text
THING://0041
└─ SOURCE
   └─ model.blend
```

But the `.blend` file is not the Thing.

It is one representation of it.

Export it.

```text
THING://0041
├─ model.blend
└─ model.glb
```

Open it somewhere else.

```text
THING://0041
├─ model.blend
├─ model.glb
└─ STAGE INSTANCE
```

Prepare it for fabrication.

```text
THING://0041
├─ model.blend
├─ model.glb
├─ STAGE INSTANCE
└─ model.stl
```

Print it.

Now something unusual has happened.

The Thing has crossed the boundary between software and matter.

But it is still recognisably descended from the same origin.

```text
SOURCE
  ↓
THING://0041
  ↓
GLB
  ↓
STAGE
  ↓
STL
  ↓
PRINT
```

That is where **TRACE** enters.

TRACE is not simply version history.

It answers:

**How did this become this?**

A useful Trace might include:

```text
ORIGIN
Blender model

↓

EXPORT
GLB generated

↓

REVISION
Jaw widened 4 mm

↓

MAKE
Print attempted

↓

FAILURE
Overhang collapsed

↓

SCAR
Unsupported geometry

↓

WEIGHT
Future fabrication requires support
```

Failure is not deleted from the story.

**SCAR = LEARNING.**

And learning changes what happens next.

**WEIGHT = MEMORY.**

The second print therefore does not begin from zero.

The system remembers what the first attempt cost.

Not emotionally.

Operationally.

A previous failure can change a warning, a proposed toolpath, a permission boundary, a recommended material or simply the amount of attention the human gives the next decision.

Memory has consequence.

Now move the same Thing somewhere else.

On an iPhone it might appear in the **Pocket**.

On Windows it might open on the **Workbench**.

On iPad it might move to the **Drafting Table**.

Inside a spatial environment it may enter the **Stage**.

```text
POCKET
   │
WORKBENCH
   │
DRAFTING TABLE
   │
STAGE
   │
THING://0041
```

These are not four Things.

They are four ways of encountering one Thing.

Different surfaces.

Same identity.

Same ancestry.

Same law.

This is the principle behind **WUKONG**.

Not a chatbot.

Not another worker.

Not a mascot.

An archetype for movement through forms while remaining recognisably oneself.

```text
TRANSFORMATION ≠ AMNESIA
```

Then something else happens.

The human selects three Things:

```text
[ SKETCH ]
[ MODEL  ]
[ AUDIO  ]
```

Thin Threads appear between them.

**THREAD = RELATIONSHIP.**

ADA notices a possible composition.

Not because ADA owns the work.

Not because an AI button has decided what the human wanted.

ADA asks:

**What belongs together?**

```text
ADA://PROPOSAL

SKETCH ─────┐
            ├── PATTERN
MODEL ──────┤
            │
AUDIO ──────┘
```

The proposal is not the decision.

The human changes it.

Pulls one Thread away.

Tightens another.

Adds a fourth Thing.

The structure responds.

Then the Threads converge.

A Knot becomes possible.

But the machine does not tie it.

The cursor does.

**KNOT = DECISION.**

```text
      THREAD
         ╲
THREAD ── ◇ ── THREAD
          ↑
        HUMAN
```

Only then does a new derivative appear.

```text
THING://0041
       │
       ├── SOURCE
       ├── REPRESENTATIONS
       ├── TRACE
       └── DERIVATIVE://0041-A
```

The new object knows what it came from.

The originals remain originals.

The relationship remains inspectable.

The decision has an author.

And consequential work leaves something behind.

A **RECEIPT**.


A receipt is not an activity feed.

It is evidence that something happened.

The completed derivative returns to the **Library**.

But Library does not mean Files.

```text
FILES     where bytes live

LIBRARY   what I have

TREE      how it belongs

THREADS   what it relates to

TRACE     how it became this

STAGE     where I work with it

ADA       how I compose something new
```

And when the Thing returns?

The Tree changes.

Not because somebody dragged a rectangle into another rectangle.

Because something actually happened.
