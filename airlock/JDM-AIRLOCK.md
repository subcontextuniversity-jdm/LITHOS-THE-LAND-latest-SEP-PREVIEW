Joshua's chamber. Not a brand splash. A pressure vessel.

## What it binds

From the public path, extended by one honest chamber:

```text
HUMAN → PLACE → SCOPE → WORK → RECEIPT → HOME
```

becomes:

```text
HUMAN → AIRLOCK → SPLIT → PLACE → SCOPE → WORK → RECEIPT → HOME
```

Bind:

- human id and display name
- node id and role (`GATOR` | `SENTINEL`)
- place (here: THE BENCH)
- thing id
- grants minus forbidden glyphs
- required grants demanded by weight already on the Thing

## What it refuses

- nameless humans
- nodes at the cursor door
- humans at the talon door
- fused login (one subject both doors)
- grants: sovereignty, golden cord, tie_knot, reset_weight, erase_scar, become_cursor, carry_past_for_human
