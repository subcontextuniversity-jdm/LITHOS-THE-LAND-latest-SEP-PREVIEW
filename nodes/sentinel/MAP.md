# Map

The system can map the past, but it cannot carry it for you.

`mapPast(session, thing)` returns origin, TRACE, scars, weight.

```text
mapped: true
carriedForHuman: false
```

Always false. If a future implementation sets that true, the grammar test should die.

Mapping is for the next pull, for the human's eyes, for the receipt. It is not a soul-file the node wears so the human doesn't have to remember Caloundra.
