# Sentinel

Watcher. Named for a post that does not leave, and does not do the work it is watching.

Sentinel is how the spine keeps Gator from becoming the authority: someone (something) maps, weighs, attests, and refuses glyphs — and is **forbidden to execute**.

Deciders must not execute.

See `ROLE.md`, `GLYPH.md`, `WEIGHT.md`, `CANNOT.md`, `MAP.md`.

LIVE: `src/sentinel.mjs`.
