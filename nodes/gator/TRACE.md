# Trace (Gator)

When Gator executes, it writes TRACE, not identity.

```text
actor  = gator-local
role   = GATOR
kind   = attempt_make | propose_remix | ...
grant  = the glyph used
```

TRACE is how this became this. It is not version history as a product feature. It is not a receipt. Receipts appear after a knot.

If the make fails, TRACE still records that Gator acted. SCAR records what was learned. WEIGHT (Sentinel) records what that costs the next pull.

Failure is not deleted from the story.
